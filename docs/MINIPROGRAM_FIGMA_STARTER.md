# 小程序 Figma 起步说明

这份起步稿的目标不是直接定稿，而是让你不用从空白画布开始。

## 文件

- `docs/miniprogram-figma-starter.svg`

## 你怎么用

1. 打开 Figma
2. 新建一个空白文件
3. 把 `miniprogram-figma-starter.svg` 直接拖进去
4. 选中导入后的内容，右键：
   - `Ungroup`
   - 如果还需要，再多解组几次
5. 开始拖拽、删改、复制

## 你先改什么

优先改这几件事：

1. 首页首屏保留哪些信息
2. 记录页四个分栏上下顺序和密度
3. 趋势页图表、统计卡、报告区块高度
4. 我的页账户信息、设置区、退出登录排布

## 这份骨架里已经给你的内容

- 4 个主页面：
  - 首页
  - 记录
  - 趋势
  - 我的
- 统一底部导航
- 常用卡片占位
- 记录页二级 tab
- picker / toast / 吸顶提示占位

## 你改的时候不用管太多的

先不用纠结：

- 精确颜色
- 阴影细节
- 字体家族
- 图标样式

你先把：

- 模块顺序
- 首屏优先级
- 卡片高低
- 留白多少
- 哪些该合并
- 哪些该删掉

这些定下来就够了。

## 你改完后怎么发我

你改完一版后，直接告诉我：

- 首页：哪些保留，哪些删
- 记录：想更紧凑还是更分明
- 趋势：图表优先还是报告优先
- 我的：想偏设置中心还是偏个人主页
- 整体：更像苹果 / 更像小米 / 更像微信原生

我再按这版骨架直接开始落代码。
